### 内容
https://sdvx.in でのパソコン上での操作性を向上させるスクリプトです
### 使用する際の注意点
このスクリプトは「Resource Override」拡張機能との併用を想定して制作しています<br>
使用する際はこれをインストールの上、管理画面で以下の設定を行ってください
```
https://sdvx.in/*/_/viewer-ui.js* → https://raw.githubusercontent.com/h-hammer001/sdvx-scroll-changer/refs/heads/main/main.js
https://sdvx.in/*/_/viewer.css*　→ https://raw.githubusercontent.com/h-hammer001/sdvx-scroll-changer/refs/heads/main/main.css
```
